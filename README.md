# Willkommen bei n8n im Codespace!

Die Umgebung wird im Hintergrund vorbereitet. Das dauert beim ersten Start ca. 5 Minuten.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/pipapolalalama/n8n_ditact2026)

## Erste Schritte
1. Unten auf "Create Workspace" klicken
2. Warten, bis das Terminal unten die Installation abgeschlossen hat.
3. Sobald n8n bereit ist, auf den Button klicken und es öffnet sich automatisch ein neuer Browser-Tab mit der n8n-Oberfläche.
4. Falls sich kein Tab öffnet: Wechseln unten im Terminal auf den Reiter **Ports** und klicken auf die Weltkugel (Open in Browser) neben Port `5678`.
